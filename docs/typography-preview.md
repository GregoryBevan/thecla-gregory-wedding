# Typography preview

A visual comparison page is available at `font-preview.html` from the project root.

It compares candidate script fonts for the site title using `Thecla & Gregory`:

- `Italianno`
- `Allura`
- `Qwitcher Grypen`
- `Parisienne`
- `Great Vibes`

The current selected direction is `Qwitcher Grypen`, which is now applied to the main site branding.
